# C# Exercises

Solutions to the exercises of my C# programming course, written in C#.

- **Chapter 2 - C# Fundamentals:** exercises 1-29
- **Chapter 3 - Object Oriented Programming:** exercises 1-16

## Project structure

```
csharp-exercises/
  chapter2/
    exercise_01.cs
    exercise_02.cs
    ...
    exercise_29.cs
  chapter3/
    exercise_01.cs
    exercise_02.cs
    ...
    exercise_16.cs
  README.md
```

Each exercise is a separate program with its own `Main` method, so each file must be run on its own (in its own project).

## How to run

1. Install the [.NET SDK](https://dotnet.microsoft.com/download).
2. Create a console project for the exercise:

   ```bash
   dotnet new console -n Exercise
   ```

3. Replace the content of `Program.cs` with the code of the exercise.
4. Run it:

   ```bash
   dotnet run
   ```
